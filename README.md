# 경매 권리 분석 서비스

사건번호 자동 수집과 사용자 문서 업로드를 지원하는 비동기 권리분석 서비스입니다.

현재는 설계 단계이며 실행 가능한 애플리케이션은 아직 없습니다.

## 아키텍처

[전체 서비스 아키텍처](docs/architecture.md)에 Mermaid 구성도, 입력별 처리 순서, 모니터링 구성, 장애 복구 원칙을 정리했습니다.

## 목표

- 법원·사건번호·물건 기준의 자동 자료 수집
- 문서 직접 업로드와 자동 수집 자료 보완
- 파싱·검증·AI 분석·근거 포함 리포트 생성
- 접수·조회 API, 수집·파싱 워커, 분석·리포트 워커의 독립 배포
- 작업 재시도·중복 방지·버전 관리
- Kubernetes 배포와 메트릭·로그·트레이스 수집

## 개발 원칙

- 핵심 코드는 직접 구현하고 AI는 설계 검토·질문·코드 리뷰에 활용합니다.
- 앱의 기능으로 AI API를 사용하는 것은 별개입니다.
- 언어와 인프라 제품은 결정 이유를 기록한 후 선정합니다.
- Go·Python 전환은 동일한 부하에서 리소스와 운영비를 비교한 뒤 결정합니다.
- 실제 문서·개인정보·인증정보·실행 데이터를 저장소에 커밋하지 않습니다.
- 예제 데이터는 합성 또는 비식별 검토를 마친 자료만 사용합니다.

## 첫 구현 순서

1. 자동 수집할 자료의 확보 경로와 이용 조건을 확인합니다.
2. 학습용 사례로 입력·출력 형식과 분석 검증 기준을 정합니다.
3. 두 입력 경로를 공통 문서 처리 흐름에 연결합니다.
4. AI 분석과 리포트를 연결하고 워커 재시작·중복 전달을 검증합니다.
5. 모니터링을 연결하고 Kubernetes에서 배포·복구를 검증합니다.
